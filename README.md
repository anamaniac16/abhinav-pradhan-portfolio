# Abhinav Pradhan · Portfolio

Interactive 3D portfolio for **Abhinav Pradhan**, graphic designer and video editor (Instagram [@tuff.fx](https://www.instagram.com/tuff.fx/)).

A floating neon temple island built in Three.js. As you scroll, the camera flies around the island and 16,000 particles morph into a film camera, pen tool, clapperboard, design layers, film reel and paper plane, while a glass flower blooms on the pedestal.

## Sections
- **Services**: graphic design, video editing, digital art and photo editing
- **Portfolio**: reel stills, digital art and album covers, branding, Lightroom and photo mode edits
- **About** and **Contact** (WhatsApp, email, Instagram)

## Run it
It's a single static page. Serve the folder with any static server (for example `npx serve .` or `python -m http.server`) and open it in a browser.

Built with Three.js r128, GSAP and Lenis, loaded from public CDNs.
